# a2b TAB Report workbook

## App

The **TAB App** ([`app/`](app/README.md)) is an offline-first, installable web app (PWA) for entering TAB field data
on a phone, tablet or laptop and exporting it into the revision 05 workbook below. It runs in local-only mode until
Supabase is configured.

```
npm install          # repository root (npm workspaces: app, packages/workbook, spike/export)
npm run dev          # http://localhost:5173
npm run lint && npm run typecheck && npm test && npm run build
```

| Folder | What it is |
|---|---|
| [`app/`](app/README.md) | The PWA (React + TypeScript + Vite, IndexedDB via Dexie) |
| [`packages/workbook/`](packages/workbook) | Shared workbook library: template map, direct-XML export, import (used by the app and the spike) |
| [`supabase/`](supabase/README.md) | Database schema, row-level security, photo storage and the Microsoft sign-in settings (not deployed yet) |
| [`spike/export/`](spike/export/README.md) | Phase 0 export spike (LibreOffice verification) |
| [`docs/`](docs) | Roadmap, tracker, required fields, workbook analysis, account setup, [screenshots](docs/screenshots) |

## After opening revision 05 in Excel for the first time

1. Accept recalculation; run **Formulas → Error Checking** (expect none).
2. **Alt+F11 → File → Import File… → `tools/vba/TABReport.bas`**, then delete the old `SyncToCPageCounts` module. The ToC button now calls the new module's routine of the same name.
3. Print-preview RTU Data, Hoods, Traverses and Building Balance.
4. Update the Calibration sheet dates and the Certification page for the current CP before use.
5. Cover page: right-click the project photo box → Change Picture… and pick the project photo.
6. Where a reading or design value cannot be obtained, type `N/A`, `Not Avail.` or `Not Acc.` in the cell (see the Abbreviations legend). The text stays in the cell; the cells computed from it stay blank and the totals and averages skip it.

## Regenerating the template

```
pip install openpyxl
python3 tools/build_workbook.py          # writes 01 - a2b_Blank_TAB_Workbook <today>.xlsm
python3 tools/build_rev02.py             # writes 02 - a2b_Blank_TAB_Workbook <today>.xlsm from the newest 01 file
python3 tools/build_rev03.py             # writes 03 - a2b_Blank_TAB_Workbook <today>.xlsm from the newest 02 file
python3 tools/build_rev04.py             # writes 04 - a2b_Blank_TAB_Workbook <today>.xlsm (02 + 03 builders with rev 04 options)
python3 tools/build_rev05.py             # writes 05 - a2b_Blank_TAB_Workbook <today>.xlsm from the newest 04 file (log: docs/build-log-rev05.txt)
python3 tools/build_evergreen.py         # writes tb-worksheet-evergreen 3 (reference).xlsx
```

Set `TAB_BUILD_DATE=m-d-yy` to control the file name.

## Verifying a build

```
python3 tools/verify_blocks.py "01 - a2b_Blank_TAB_Workbook <date>.xlsm"   # every unit block vs block 1
python3 tools/verify_links.py  "01 - a2b_Blank_TAB_Workbook <date>.xlsm"   # Data <-> Airflow <-> Data Entry links (rev 01 only)
python3 tools/functional_test.py "01 - a2b_Blank_TAB_Workbook <date>.xlsm" # sample data, recalc, 61 expected values (rev 01)
python3 tools/functional_test_rev02.py "02 - a2b_Blank_TAB_Workbook <date>.xlsm" # 68 expected values (rev 02)
python3 tools/functional_test_rev03.py "03 - a2b_Blank_TAB_Workbook <date>.xlsm" # 99 expected values (rev 03)
python3 tools/functional_test_rev04.py "04 - a2b_Blank_TAB_Workbook <date>.xlsm" # 133 expected values (rev 04)
python3 tools/build_rev05.py --selftest "04 - a2b_Blank_TAB_Workbook <date>.xlsm"  # formula parser round-trip + transform cases
python3 tools/functional_test_rev05.py "05 - a2b_Blank_TAB_Workbook <date>.xlsm"  # 265 checks (rev 04 checks, same results as rev 04, N/A notations, stress, profile curve, MAU method list, Building Balance small fans, 24" x 24" supply filter)
```

The functional test needs LibreOffice Calc (`apt-get install libreoffice-calc`; `libreoffice-core` alone reports "source file could not be loaded" for every spreadsheet); for realistic page previews also install `fonts-crosextra-carlito` (Calibri-metric). Every change is a function in `tools/build_workbook.py` / `tools/build_steps2.py`; the build log is written to `docs/build-log.txt`.
