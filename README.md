# a2b TAB Report workbook

| File | What it is |
|---|---|
| `01 - a2b_Blank_TAB_Workbook 9-9-26.xlsm` | **Current template** (revision 01). Generated by `tools/build_workbook.py` from the 4-16-26 original. |
| `00 - a2b_Blank_TAB_Workbook 4-16-26.xlsm` | Previous template, kept as backup. |
| `tb-worksheet-evergreen 3 (reference).xlsx` | Cleaned CaptiveAire / Evergreen field worksheet (constants used by the Hoods and MAU Supply Methods pages). |
| `tb-worksheet-evergreen 2.xlsx` | Original CaptiveAire worksheet with job data, kept as backup. |
| `docs/TAB-Report-Review.md` | Review findings, NEBB gap analysis, Evergreen alignment, format recommendations, change log. |
| `tools/vba/TABReport.bas` | Macro module to import once: ToC page sync, hide unused blocks, interleaved Data/Airflow printing. |

## After opening revision 01 in Excel for the first time

1. Accept recalculation; run **Formulas → Error Checking** (expect none).
2. **Alt+F11 → File → Import File… → `tools/vba/TABReport.bas`**, then delete the old `SyncToCPageCounts` module. The ToC button now calls the new module's routine of the same name.
3. Print-preview RTU Data, Hoods, Traverses and Building Balance.
4. Update the Calibration sheet dates and the Certification page for the current CP before use.

## Regenerating the template

```
pip install openpyxl
python3 tools/build_workbook.py          # writes 01 - a2b_Blank_TAB_Workbook <today>.xlsm
python3 tools/build_evergreen.py         # writes tb-worksheet-evergreen 3 (reference).xlsx
```

Set `TAB_BUILD_DATE=m-d-yy` to control the file name. Every change is a function in `tools/build_workbook.py` / `tools/build_steps2.py`; the build log is written to `docs/build-log.txt`.
